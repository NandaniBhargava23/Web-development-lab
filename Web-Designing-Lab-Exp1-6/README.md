# Web Designing Lab: Experiments 1–6
Six beginner-friendly runnable projects for JCS 308/408. Extract the ZIP and open this folder in VS Code. Open each experiment's index.html using Live Server (or a browser). Read each folder's README for aim, resources, procedure, and screenshot checklist. Replace sample student details and take your own screenshots before submission. Include all HTML/CSS/JS files. Experiment 5 needs internet but no API key.

Folders: exp1-github, exp2-portfolio, exp3-todo, exp4-seo-accessibility, exp5-weather, exp6-responsive-blog.
