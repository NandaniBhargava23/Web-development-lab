# Experiment 2: Personal portfolio
Aim: Design a portfolio using HTML and CSS with navigation, About, Projects, and Contact.
Resources: VS Code, browser, HTML5, CSS3.
Procedure: Open index.html with Live Server. Replace the sample name, bio, project details, and email with your own. Test the navigation and form labels. Capture screenshots of the main page and sections.
Result: A personal portfolio webpage was created. The form is a front-end demo and does not send email without a backend/service.
