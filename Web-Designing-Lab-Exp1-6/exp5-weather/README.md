# Experiment 5: Weather app using Fetch API
Aim: Fetch current weather for a city entered by the user.
Resources: VS Code, browser, internet, HTML/CSS/JavaScript, Fetch API, Open-Meteo.
Procedure: Open index.html with Live Server. Search Delhi, Noida, or another city. Observe temperature, condition, humidity, and wind. Test an unknown city and capture both result and error screenshots.
Result: The app fetches weather data from Open-Meteo. No API key is required; internet is required.
