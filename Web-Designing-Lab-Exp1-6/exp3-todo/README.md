# Experiment 3: Dynamic to-do list
Aim: Add, delete, and mark tasks complete using JavaScript and DOM manipulation.
Resources: VS Code, browser, HTML, CSS, JavaScript.
Procedure: Open index.html with Live Server. Add a few tasks, tick one as complete, remove one, and test submitting a blank task. Capture a screenshot showing tasks and a completed item.
Result: A dynamic task list was created. Tasks remain only while the page is open.
