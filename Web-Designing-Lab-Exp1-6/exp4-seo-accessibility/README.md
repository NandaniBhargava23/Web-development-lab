# Experiment 4: SEO and Accessibility
Aim: Improve a webpage for search engines and accessibility with semantic HTML, heading structure, and metadata.
Resources: VS Code, browser, HTML5, CSS3.
This page demonstrates a descriptive title and meta description, language and viewport metadata, semantic header/nav/main/section/footer, one H1 followed by H2 headings, descriptive link text, labelled form fields, and visible keyboard focus.
Procedure: Open index.html. Use Tab to test navigation and form focus; resize the browser; take a screenshot and include the source code.
Result: A semantic, accessible webpage with basic SEO metadata was created.
