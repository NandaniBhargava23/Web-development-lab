# Experiment 6: Responsive blog with Bootstrap
Aim: Build a blog page that adapts to different screen sizes using CSS media queries and Bootstrap.
Resources: VS Code, browser, HTML, CSS, Bootstrap 5 CDN.
Procedure: Open index.html with Live Server and internet access. Inspect the navbar and cards. Resize to mobile and desktop widths and take screenshots of both layouts.
Result: A responsive blog page was created with Bootstrap grid/components and a custom media query.
